depth-chat · Mock 数据 Demo 说明

本目录在 smoneyfuturesservice/depth-chat.html 原页基础上， 仅增加 配置变量 与 mock 桥接（head 内 2 行 script，sync 后自动注入）。 页面 UI / 业务逻辑与原版一致。

打开 depth-chat（走 api_base 真接口） 打开 depth-chat（Mock 模式） Mock · TRX 1000003 返回 quant-visual-tools 首页

1. 配置变量 api_base

配置文件：config/api-config.json

{
  "api_base": "http://18.177.36.184/futures",
  "endpoints": {
    "depth": "/debug/depth",
    "klineDiff": "/debug/klineDiff"
  }
}
备注：非 mock 模式下，页面内 #market_monitor / #market_kline 下拉框会被重写为 {api_base}/debug/depth 与 {api_base}/debug/klineDiff。 可通过 URL 覆盖：?api_base=http://18.177.36.184/futures

2. Mock 开关

方式说明
?mock=1推荐。拦截 /debug/depth 与 /debug/klineDiff，改读本地 JSON
config/api-config.json设置 mock.enabled_by_default: true 默认 mock
桥接脚本js/mock-bridge.js — 在 jQuery 就绪后 patch $.ajax
注意：mock 仅覆盖 /debug/depth 与 /debug/klineDiff。 牌价、exchangeInfo、depthGather、币安深度等仍走外网；离线演示时这些区块可能为空，属预期行为。

3. Mock 文件命名

目录：data/mock/

接口文件规则回退
GET /debug/depth?symbol_id= depth.symbol-{symbol_id}.json depth.default.json
GET /debug/klineDiff?symbol_id=&resolution=&size=&from=&to= klineDiff.symbol-{symbol_id}.json klineDiff.default.json

已内置示例：

  • 1000001 — BTCUSDT（depth.symbol-1000001.json）
  • 1000003 — TRXUSDT（depth.symbol-1000003.json，与截图交易对一致）

4. 响应外壳（统一）

与线上一致，前端读 json.data：

{
  "code": 0,
  "msg": "success",
  "data": { ... }

5. /debug/depth 数据结构

来源：smoneyfuturesservice/script/src/Controller/Debug/Depth.php::index()

5.1 data.stats — 顶栏指标

字段含义示例
ask_price最优卖价 AP0.25350
bid_price最优买价 BP0.25344
mark_price标记价 MP0.25347
diff_price盘口差（万分比 ‱）2.37
ask_qty卖盘总量（标的量）9900
bid_qty买盘总量（标的量）10980
uid_num挂单 UID 数8
order_num挂单笔数24

5.2 data.depth.ask / bid — 用户挂单详情（数组）

每条委托（用于「用户挂单详情」Tab）：

{
  "price": 0.25350,
  "trust_id": 900001,
  "rest_qty": 100,
  "number": 100.0,
  "user_id": 10001,
  "action": 0,
  "source": 1,
  "intval_time": "3s",
  "date": "2026-08-11 12:00:00",
  "liquidated": 0,
  "trust_info": { "pid": 1, "type": 1, "qty": 100, "margin": "10", ... }
}
备注：rest_qty = 张数；number = 标的量 = 张数 × contract_value。 source：1 Web / 2 App / 3 Schedule / 4 强平。

5.3 data.asks / data.bids — 累计深度（面积图 + 50 档对比）

二维数组 [价格, 累计标的量]，与 PHP 侧 $newAsksData / $newBidsData 一致：

"asks": [[0.25350, 100.0], [0.25353, 250.0], ...],
"bids": [[0.25344, 120.0], [0.25341, 285.0], ...]
备注：asks 按价格升序，bids 按价格降序；第二列为累计标的量（前端会 decumulate 成单档量）。

5.4 data.depth_analyze

HTML 字符串，深度图 tooltip 展示，格式：_{百分比} : {买量} / {卖量} <br/>

6. /debug/klineDiff 数据结构

来源：Debug/Index.php::klineDiff() + KlineLogic::kline()

请求参数（页面固定拼法）：

?symbol_id=1000003&resolution=1&size=1000&from={unix}&to={unix}
{
  "code": 0,
  "msg": "success",
  "data": {
    "last": {
      "symbolId": 1000003,
      "symbolName": "TRXUSDT",
      "kline": [
        { "t": 1786424157, "o": 0.25347, "h": 0.25367, "l": 0.25331, "c": 0.25347, "v": 50000 }
      ]
    },
    "mark": {
      "symbolId": 1000003,
      "symbolName": "TRXUSDT",
      "kline": [
        { "t": 1786424157, "o": 0.25347, "h": 0.25367, "l": 0.25331, "c": 0.25347 }
      ]
    }
  }
}
备注：t 为 Unix 秒级时间戳；last.kline 含成交量 v，mark.kline 无 v。 展开 K 线面板后每 5s 拉取一次。
