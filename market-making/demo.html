打开铺单页 Mock 深度 symbol-1000001.json 总索引 返回首页

1. 数据文件 data/symbol-1000001.json

{
  "list": [ /* 铺单任务 mx_market_making_list */ ],
  "boxes": {
    "1": [ /* PID=1 网格层 mx_market_making_box */ ],
    "2": [ /* PID=2 */ ]
  },
  "active_pid": 1
}

2. list[] 主要字段

字段说明
pid / symbol_id / symbol任务 ID、交易对
mark_price标记价（驱动价档计算）
contract_value / price_precision单张价值、价格精度
benchmark_exchange / strategy对标平台、策略

3. boxes[] 网格字段

字段说明
direction1 买盘 / -1 卖盘
dom层级
price_float相对 Mark 百分比，如 100.005-100.3
number_float固量区间（张）
change_number_float / change_survival_time变动单区间 / 过期

4. Mock 来源

  • js/mock-data.js — file:// 内嵌（list + boxes + depth）
  • ../config/app-config.json — 全局 endpoint / mock 开关
  • 深度 mock：../depth-chat/data/mock/depth.symbol-{id}.json
