量化展示工具

从 quant-admin / smoneyfuturesservice 提取的独立静态页面，本地 HTTP 服务即可使用。

quant-admin 铺单

① MX 铺单工具

对应 9527.php/mx_market_making_list + 铺单盒子。深度图 + 铺单配置表，前端按精度计算价档数、固量区间、挂单量。

 smoneyfuturesservice 深度 V4

② depth-chat

深度服务 V4：本所 vs 币安深度对比、50 档表格、K 线。源码 sync 拷贝 + mock 配置（见 demo.html 说明）。

 smoneyfuturesservice 聚合

③ depthGather-chat

深度聚合页：按 UID 聚合的买卖盘明细 + 深度图。源码原样拷贝，未改动。
启动方式：./start.sh 或 python3 -m http.server 8080
同步 depth 页：./sync.sh（从 smoneyfuturesservice 重新拷贝）
详细说明见 README.md
