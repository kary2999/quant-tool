本所深度与 Binance、OKX、Bybit、KuCoin 横向对齐，统一精度后 比较同一价位区间的挂单厚度，判断自家盘口在市场中的相对位置。

打开工具 → README
独立项目 回测

K 线回测

基于币安公开行情的纯前端回测：导入成交 CSV 或用自然语言描述策略， 输出净盈亏、胜率、盈亏比、最大回撤与权益曲线，并给出最优下车点对比。
